# PMP Guide - Project Management Learning

A comprehensive online learning platform for Project Management fundamentals and PMP exam preparation.

## 📚 Overview

This project provides interactive learning materials covering:
- **Software Project Management** fundamentals
- **SDLC** (Software Development Life Cycle) concepts
- **Triple Constraint Triangle** (Time, Cost, Scope)
- **Work Breakdown Structure** (WBS) with real case studies
- **PMBOK Framework** and project management processes
- **PMP Exam Preparation** materials

## 🚀 Features

### Two Learning Paths:

1. **Starting Learner Path** 🎓
   - Introduction to project management
   - SDLC overview
   - Project lifecycle phases
   - Triple constraints explanation
   - Quality and configuration management
   - Common methodologies (Agile, Prototype, Waterfall)

2. **PMP Exam Preparation Path** 🎯
   - Deep dive into triple constraints
   - Detailed WBS breakdown with Scholar Academy case study
   - PMBOK framework (5 process groups, 10 knowledge areas)
   - Prototype methodology details
   - Change and risk management
   - QA vs QC comparison
   - Exam tips and success factors

## 📊 Key Concepts

### Triple Constraint Triangle
- **Time**: Schedule, deadlines, milestones, critical path
- **Cost**: Budget, resources, ROI
- **Scope**: Features, functions, requirements, scope creep

### PMBOK Framework
- **5 Process Groups**: Initiating, Planning, Executing, Monitoring & Controlling, Closing
- **10 Knowledge Areas**: Integration, Scope, Time, Cost, Quality, Resource, Communication, Risk, Procurement, Stakeholder
