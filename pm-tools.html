PM Tools

Tools for planning and tracking

Each tool answers one question a project manager is asked every week. They all use the same example project, the Scholar Academy school system, so you can see one plan from four angles.

How they fit together

In planning, you usually work in this order: decide who does what, work out the sequence and what controls the end date, draw the schedule, then pick the checkpoints you'll report on.
