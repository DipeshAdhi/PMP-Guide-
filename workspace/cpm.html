Critical Path Method (CPM)

The critical path is the longest chain of dependent activities from start to finish. Its length is the shortest time the project can take. Any delay on it delays the whole project; activities off it have "float" and can slip a little without harm.

In short: CPM is a schedule network analysis technique used in Develop Schedule. It calculates the early and late start and finish dates of every activity, and the total float of each one.

Key terms

ES

Early start

Earliest day the activity can start.

EF

Early finish

ES + duration.

LS

Late start

Latest start without delaying the project.

LF

Late finish

Latest finish without delaying the project.

TF

Total float

LS − ES. Slip allowed before the project is late.

FF

Free float

Slip allowed before the next activity is late.

PERT: estimating a duration when you're unsure

CPM needs a duration for every activity. When an estimate is uncertain, PERT (three-point estimating) combines an optimistic, a most likely, and a pessimistic guess into one weighted estimate.

Formulas:
E = (O + 4M + P) ÷ 6 (beta / PERT)
σ = (P − O) ÷ 6 (standard deviation)
E = (O + M + P) ÷ 3 (triangular, simple average)

Shortening the schedule

Only shortening critical activities shortens the project.

  • Crashing: add resources (overtime, more people) to critical activities. Costs more money. Crash the cheapest critical activity first.
  • Fast tracking: do activities in parallel that were planned in sequence. Costs nothing extra but adds risk and possible rework.

Watch out: shorten the critical path enough and another path becomes critical, so savings shrink.

Convention: start at day 0 or day 1?

This page uses the day 0 convention: the first activity has ES = 0 and EF = ES + duration. Some books start at day 1 and use EF = ES + duration − 1. Both give the same critical path and float. Just don't mix them in one calculation.

📝 Key points to remember

  • The critical path is the longest path, with zero total float (normally). It is not the path with the most activities or the most expensive ones.
  • There can be more than one critical path. More critical paths means more schedule risk.
  • Negative float means the project is already behind its required finish date.
  • Forward pass → ES, EF (take the max at merges). Backward pass → LS, LF (take the min at bursts).
  • Quick check: list every path with its total duration. The biggest total is the critical path.
  • PERT: (O + 4M + P) ÷ 6; standard deviation (P − O) ÷ 6; ±1σ ≈ 68%, ±2σ ≈ 95%, ±3σ ≈ 99.7%.
